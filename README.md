# PocketWise – Expense Tracker

A React and Vite expense tracker with separate User and Admin modules.

## Modules
- User Management
- Expense and Income Management
- Budget and Category Management
- Account and Recurring Expense Management
- Reports and Analytics
- Admin Dashboard

## Features
- User registration and login
- Add, view, edit and delete transactions
- Expense categories
- Income and expense totals
- Category budgets
- Cash, bank and wallet accounts
- Recurring payment records
- Monthly charts and category-wise spending reports
- Admin user management
